# Hafıza Oyunu (Memory Game)

Bu proje, HTML, CSS ve JavaScript kullanılarak geliştirilmiş, tarayıcı tabanlı interaktif bir hafıza oyunudur. Kullanıcılar tek başlarına zamana karşı yarışabilir veya bir arkadaşlarıyla karşılıklı oynayabilirler.

## Özellikler

- **İki Farklı Oyun Modu:** - **Tek Kişilik:** En az hamle ve en kısa sürede tüm çiftleri bulmaya çalışın.
  - **İki Kişilik:** Arkadaşınızla yarışın, en çok çifti bulan kazanır!
- **Üç Zorluk Seviyesi:**
  - **Basit:** 24 Kart (4x6 Grid)
  - **Orta:** 50 Kart (5x10 Grid)
  - **Zor:** 98 Kart (7x14 Grid)
- ** Dinamik Arayüz:** Seçilen zorluğa göre kart boyutları ve grid yapısı otomatik olarak ayarlanır.
- ** Görsel Efektler:** Oyun sonunda `canvas-confetti` kütüphanesi ile kutlama efekti.
- ** Responsive Tasarım:** Mobil cihazlar ve farklı ekran boyutlarıyla tam uyumlu.

##Kullanılan Teknolojiler:
- HTML5: Yapısal iskelet.
- CSS3: Flexbox, Grid Layout ve modern cam (glassmorphism) tasarımı.
- JavaScript (ES6+): Oyun mantığı, zamanlayıcı ve DOM yönetimi.
- Canvas-Confetti: Kazanma kutlamaları için harici kütüphane.
