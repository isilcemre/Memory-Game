# Memory Game

This project is a browser-based interactive memory game developed using HTML, CSS, and JavaScript. Users can compete against time in single-player mode or play against a friend in multiplayer mode.

## Features

- **Two Different Game Modes:**
  - **Single Player:** Try to find all pairs in the shortest time and with the fewest moves.
  - **Two Players:** Compete with a friend; the one who finds the most pairs wins!
- **Three Difficulty Levels:**
  - **Easy:** 24 Cards (4x6 Grid)
  - **Medium:** 50 Cards (5x10 Grid)
  - **Hard:** 98 Cards (7x14 Grid)
- **Dynamic Interface:** Card sizes and grid structures adjust automatically based on the selected difficulty.
- **Visual Effects:** A celebration effect using the `canvas-confetti` library at the end of the game.
- **Responsive Design:** Fully compatible with mobile devices and various screen sizes.

## To run the project on your local computer, follow these steps:

1. Clone this repository:
   [https://github.com/isilcemre/Memory-Game.git](https://github.com/isilcemre/Memory-Game.git)
2. Navigate to the project folder.
3. Open the index.html file in any modern web browser.

## Technologies Used:
- HTML5: Structural skeleton.
- CSS3: Flexbox, Grid Layout, and modern glassmorphism design.
- JavaScript (ES6+): Game logic, timer, and DOM management.
- Canvas-Confetti: External library for winning celebrations.



# Hafıza Oyunu

Bu proje, HTML, CSS ve JavaScript kullanılarak geliştirilmiş, tarayıcı tabanlı interaktif bir hafıza oyunudur. Kullanıcılar tek başlarına zamana karşı yarışabilir veya bir arkadaşlarıyla karşılıklı oynayabilirler.

## Özellikler

- **İki Farklı Oyun Modu:** - **Tek Kişilik:** En az hamle ve en kısa sürede tüm çiftleri bulmaya çalışın.
  - **İki Kişilik:** Arkadaşınızla yarışın, en çok çifti bulan kazanır!
- **Üç Zorluk Seviyesi:**
  - **Basit:** 24 Kart (4x6 Grid)
  - **Orta:** 50 Kart (5x10 Grid)
  - **Zor:** 98 Kart (7x14 Grid)
- ** Dinamik Arayüz:** Seçilen zorluğa göre kart boyutları ve grid yapısı otomatik olarak ayarlanır.
- ** Görsel Efektler:** Oyun sonunda `canvas-confetti` kütüphanesi ile kutlama efekti.
- ** Responsive Tasarım:** Mobil cihazlar ve farklı ekran boyutlarıyla tam uyumlu.
